## 5. Architectural Conventions & Data Flow

### 5.1 Single Source of Truth (`src/data/profile.ts`)
- All personal profile information, work history, projects, skills, education, awards, blog posts, and workstation specs **must reside in `src/data/profile.ts`**.
- Data structures are strongly typed with explicit TypeScript interfaces:
  - `EducationItem`
  - `WorkExperienceItem`
  - `ProjectItem`
  - `AwardItem`
  - `BlogItem`
  - `DeviceCategory`
- **Rule**: Do not hardcode portfolio facts or project copy directly into section components. Update `profile.ts` and ensure components consume from it.

### 5.2 View & Routing Architecture (`src/App.tsx`)
- The portfolio operates as a hybrid Single Page Application (SPA) driven by state and hash routing:
  - `activeView`: `'main' | 'blogs' | 'devices'`
  - On `'main'`, all primary sections (`#overview`, `#education`, `#experience`, `#projects`, `#skills`, `#awards`) render sequentially.
  - On `'blogs'` and `'devices'`, dedicated full-page sub-views render with back buttons to return to `'main'`.
- Synchronized with browser history via `hashchange` and `popstate` listeners to preserve browser Back/Forward navigation.
- Smooth scrolling accounts for offset headers when navigating directly via hash links.

### 5.3 Interactive AI Assistant (`src/components/AIQueryModal.tsx`)
- Accessible via:
  - Global keyboard shortcut: `Cmd+K` (macOS) or `Ctrl+K` (Windows/Linux)
  - Floating trigger button on the bottom right
  - Overview hero action buttons
- **Intent Matching**: Uses `getAIResponse(query)` with keyword-based heuristic parsing for fast, offline responses covering Herald's RAG experience, Loam Shopify store, Naga City internship, academic GWA, certifications, awards, and contact info.
- **Deep Linking**: Responses can contain `sectionId` or `viewId` actions that automatically navigate the portfolio when clicked.
- **Rule**: If new projects, experiences, or major milestones are added to `profile.ts`, update `PRESET_QUESTIONS` and keyword intents in `AIQueryModal.tsx` to maintain consistency.

### 5.4 Sidebar & Navigation (`src/components/Layout/Sidebar.tsx`)
- **Desktop**: Fixed sticky sidebar with collapse/expand toggle (`desktopCollapsed` state).
  - Expanded: `270px` width with full labels and section icons.
  - Collapsed: `70px` width showing compact icon navigation.
  - Dynamic scroll spy highlights the active section in view.
- **Mobile (< 1024px)**: Top sticky navigation bar with a hamburger toggle and slide-over drawer backdrop. Traps scroll (`overflow: hidden`) and listens to `Escape` key to close.

## 6. Design System & Styling Guidelines

- **Style Philosophy**: Clean, straightforward minimalist design. Dark text on clean white/subtle zinc surfaces with refined borders (`#e4e4e7`), precise typography, and subtle shadows.
- **CSS Variables** (`src/styles/variables.css`):
  - Surfaces: `--bg-main` (`#ffffff`), `--bg-sidebar` (`#fafafa`), `--bg-surface` (`#ffffff`), `--bg-muted` (`#f4f4f5`)
  - Text: `--text-primary` (`#09090b`), `--text-secondary` (`#52525b`), `--text-muted` (`#71717a`)
  - Borders: `--border-color` (`#e4e4e7`), `--border-dark` (`#09090b`)
  - Fonts:
    - Display / Headings: `--font-display` (`'Space Grotesk'`)
    - Body: `--font-sans` (`'Inter'`)
    - Monospace / Code / Tags: `--font-mono` (`'JetBrains Mono'`)
- **Responsive Breakpoints**:
  - Desktop: `>= 1024px`
  - Tablet & Mobile: `< 1024px` (switches layout to vertical column with mobile header)
  - Small Mobile: `< 640px` (adjusts paddings, button grids, and typography sizes)
- **Component Classes**: Use existing utility and component classes from `global.css` (e.g., `.clean-card`, `.pill-tag`, `.btn-primary`, `.btn-secondary`, `.section-label`, `.section-title`, `.portfolio-section`).

## 8. Best Practices for Modifying the Codebase

1. **Strict TypeScript**: Do not introduce untyped `any` or suppress errors with `@ts-ignore` unless strictly justified.
2. **React 19 Hooks Compliance**:
   - Avoid calling `setState` synchronously within the body of a `useEffect` unless reacting to external subscription changes.
   - For resetting component state when a modal closes or props change, prefer key resetting (`<Modal key={isOpen ? 'open' : 'closed'} />`) or triggering resets in user action handlers (`onClose()`).
3. **Keep HTML Semantic & Accessible**:
   - Maintain appropriate heading hierarchy (`<h1>` in Overview hero, `<h2>` for section titles, `<h3>` for cards).
   - Retain ARIA labels on icon buttons (`aria-label`, `aria-hidden`).
   - Retain keyboard accessibility (Esc to close drawers/modals, Cmd+K / Ctrl+K for search).
4. **Preserve SEO Meta & Structured Data**:
   - Ensure changes affecting personal credentials or domains keep `index.html` Schema.org JSON-LD and OpenGraph tags in sync.
5. **No Heavy Dependencies Without Justification**:
   - The project is lightweight and performant. Avoid adding large UI component libraries or CSS runtime engines. Stick to the built-in CSS design tokens.
